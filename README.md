# Учебный стенд au-team.irpo — ДЭ 09.02.06

Документация сети и команды настройки стенда на ALT Linux в порядке заданий
КИМ 09.02.06-1-2027 (профильный уровень).

- `index.html` — Модуль 1: сетевая инфраструктура (документация + задания 1–11)
- `module2.html` — Модуль 2: сетевое администрирование (задания 1–9, черновик)

## Возможности

- **Параметры сети** (кнопка ⚙): интерфейсы, адреса, VLAN, порты, пароль, домен.
  После «Пересобрать команды» значения подставляются во все блоки, таблицы и схему.
  Есть проверка подсетей, пресет «Маски по КИМ», экспорт/импорт JSON.
  Параметры хранятся в браузере (localStorage) и общие для обеих страниц.
- Копирование блока одной кнопкой; для выбранной ВМ — «Скопировать всё» и «Скачать .sh».
- Отметки «готово» с прогрессом по шагам, поиск по командам, фильтр по ВМ.
- Подсветка синтаксиса и подставляемых значений, сворачивание длинных блоков.
- Версия для печати (Ctrl+P), вертикальная схема на телефоне.
