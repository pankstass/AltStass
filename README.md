# Учебный стенд au-team.irpo — ДЭ 09.02.06

Документация сети и команды настройки стенда на ALT Linux в порядке заданий
КИМ 09.02.06-1-2027 (профильный уровень). Версия сайта 1.4.

| Файл | Страница |
|---|---|
| `index.html` | Главная: модули с прогрессом, «Где теряют баллы», занятия и снапшоты, состав стенда |
| `m1-network.html` | Модуль 1 · Настройка сетевой инфраструктуры (Задание 1, занятия №3–9) |
| `m2-admin.html` | Модуль 2 · Организация сетевого администрирования (Задание 2, занятия №10–12) |
| `m3-services.html` | Модуль 3 · Эксплуатация объектов сетевой инфраструктуры (Задание 3, занятия №13–15) |

Имена страниц модулей — `m<N>-<тема>.html`: `m<N>` совпадает с номером модуля и ключом
отметок в браузере. Старые адреса (`module2.html`, `index.html#t5`) переадресуются автоматически.
Правила именования — в [DOCUMENTATION.md, раздел 3.1](DOCUMENTATION.md#31-правила-именования).

## Возможности

- **Параметры сети** (кнопка ⚙): интерфейсы, адреса, VLAN, порты, пароль, домен, параметры Модуля 3.
  После «Пересобрать команды» значения подставляются во все блоки, таблицы и схему.
  Есть проверка подсетей, пресет «Маски по КИМ», экспорт/импорт JSON.
  Параметры хранятся в браузере (localStorage) и общие для всех страниц.
- Копирование блока одной кнопкой; для выбранной ВМ — «Скопировать всё» и «Скачать .sh».
- Отметки «готово» с прогрессом по шагам и по модулям на главной, поиск по командам, фильтр по ВМ.
- Подсветка синтаксиса и подставляемых значений, сворачивание длинных блоков.
- Версия для печати (Ctrl+P), вертикальная схема на телефоне.
- Метка «✓ стенд» у блоков, выполненных на стенде автора, и подсказка «Ожидается» с образцом вывода у проверок.

```

assets/params.js   — схема параметров, проверка и вычисление производных значений
assets/app.js      — интерфейс модулей: параметры, копирование, отметки, фильтр, поиск
assets/home.js     — главная: параметры и прогресс по модулям
assets/logo.webp, favicon.png, og-image.png
tools/build.py, tools/src/, tools/tests/ — сборка и тесты
```
