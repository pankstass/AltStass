Контроллер домена Samba DC

Домен поднимается на BR-SRV с внутренним DNS Samba. HQ-CLI по-прежнему использует DNS HQ-SRV, поэтому на HQ-SRV добавляются SRV-записи, указывающие на контроллер. HQ-CLI вводится в домен через winbind; входить могут только члены группы hq, домашний каталог создаётся автоматически. Kerberos чувствителен ко времени: при ошибке Clock skew сначала выполните задание 4.

Файловое хранилище RAID 0

Массив md0 из двух дополнительных дисков, ext4 прямо на массиве, монтирование в /raid по UUID с nofail (система загрузится даже без массива). Имена дисков проверьте по lsblk.

HQ-SRVmdadm, файловая система, fstab✓ стенд
apt-get install -y mdadm
lsblk
mdadm --zero-superblock --force /dev/sdb /dev/sdc 2>/dev/null
mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdb /dev/sdc --run
mkfs.ext4 -F /dev/md0
grep -q '^ARRAY /dev/md0' /etc/mdadm.conf || mdadm --detail --scan >> /etc/mdadm.conf
mkdir -p /raid
grep -q ' /raid ' /etc/fstab || printf 'UUID=%s /raid ext4 defaults,nofail 0 0\n' "$(blkid -s UUID -o value /dev/md0)" >> /etc/fstab
systemctl daemon-reload && mount -a
cat /proc/mdstat
df -h /raid
HQ-SRVПроверка после перезагрузки✓ стенд
cat /proc/mdstat
df -h /raid
grep -E 'md0|/raid' /etc/mdadm.conf /etc/fstab
Ожидается

Статическая трансляция портов

Таблица nftables из задания 8 Модуля 1 дополняется цепочкой prerouting (DNAT), файл /etc/nftables/nftables.nft перезаписывается целиком. Условие ip daddr вместо iifname позволяет проверять проброс и из своего офиса (с HQ-CLI).

HQ-RTRDNAT на HQ-SRV✓ стенд
cat > /etc/nftables/nftables.nft << 'EOF'
#!/usr/sbin/nft -f
flush ruleset

table ip nat {
    chain prerouting {
        type nat hook prerouting priority dstnat; policy accept;
        ip daddr 172.16.1.2 tcp dport 8080 dnat to 10.0.100.20:80
        ip daddr 172.16.1.2 tcp dport 2027 dnat to 10.0.100.20:2027
    }

    chain postrouting {
        type nat hook postrouting priority srcnat; policy accept;
        oifname "enp0s10" masquerade
    }
}
EOF
systemctl enable --now nftables
systemctl restart nftables
nft list ruleset
