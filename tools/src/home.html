Как пользоваться

  1. Задайте параметры. На странице любого модуля нажмите «⚙ Параметры сети» и укажите свои интерфейсы, адреса и пароли — значения общие для всех модулей и хранятся в браузере.
  2. Выполняйте по шагам. Шаги идут в порядке пунктов КИМ; у каждого блока — метки ВМ, кнопка «Копировать» и отметка «готово». Фильтр по ВМ собирает все её команды в один .sh.
  3. Сверяйте вывод. У проверок есть подсказка «Ожидается».
  4. Фиксируйте состояние. После каждого занятия — снапшот на выключенной ВМ (poweroff), имена — по паспорту стенда.
